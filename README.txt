# Portfolio Anisa Trizaskia

Website portfolio video editor yang dibuat berdasarkan screenshot referensi.

## Struktur
- `index.html` — struktur halaman
- `style.css` — seluruh styling/layout
- `script.js` — menu mobile + modal portfolio
- `assets/` — gambar hasil crop dari screenshot referensi

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka foldernya di Visual Studio Code.
3. Install extension **Live Server** jika ingin preview otomatis.
4. Klik kanan `index.html` → **Open with Live Server**.

Bisa juga langsung double-click `index.html` untuk membukanya di browser.

## Mengganti data
- Nama/deskripsi: edit `index.html`
- Warna, ukuran, layout: edit `style.css`
- Link Instagram/YouTube/TikTok: ubah `href="#"` pada bagian social media.
- Email: ganti `gmail@example.com`.
- Gambar portfolio: ganti file di folder `assets/` dengan gambar sendiri menggunakan nama file yang sama.
